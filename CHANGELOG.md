# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-10

### Added
- **Initial release of the `openum` library.**
- Module for Ordinary Differential Equations (`ODE`).
- Module for Partial Differential Equations (`PDE`).
- Module for Boundary Value Problems (`BVP`).
- Module for Monte Carlo simulations (`MC`).
- Modules for numerical integration (`numint`) and differentiation (`numdiff`).
- Modules for solving linear (`NumLinEqu`) and non-linear equation systems (`NonLinEq`).
- Module for interpolation (`Interpolation`).
- Module for numerical eigenvalue calculation (`NumEigenv`).
- Module for error calculation (`Errorcalc`).
- Comprehensive documentation and example scripts added.
